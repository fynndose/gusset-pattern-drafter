Unsigned app warnings

Gusset is not signed with a paid developer certificate yet, so Windows and macOS warn you the first time you start it. The warning means the system does not know who made the file. It says nothing about what is in it.

To be sure your download is complete and unchanged, compare its checksum. Only follow these steps for a file you downloaded from this site.

Jump to Windows, Mac or Linux.

Windows: "Windows protected your PC"

  1. Your browser may say the file is not commonly downloaded. In Edge or Chrome, open the download's menu (the three dots) and choose Keep.
  2. Double-click the file. A blue box says Windows protected your PC.
  3. Click More info. The file's name and "Unknown publisher" appear.
  4. Click Run anyway.

The installer sets Gusset up for your user only and asks for no administrator password. The portable .exe needs no installation. It unpacks itself at each start, which takes a few seconds.

Mac: "Open Anyway"

  1. Open the .dmg and drag Gusset – Pattern Drafter to the Applications folder.
  2. Start it from Applications. macOS blocks it the first time. Click Done, not Move to Trash.
  3. Open System Settings, then Privacy & Security, and scroll down to the message about Gusset.
  4. Click Open Anyway and confirm with your password. From then on it starts normally.

If macOS says the app "is damaged and can't be opened"

The file is not damaged. macOS says this about some downloaded apps that Apple has not signed. Open Terminal (in Applications, Utilities) and run this line, then start the app again:

xattr -cr "/Applications/Gusset – Pattern Drafter.app"

This removes the mark macOS puts on downloaded files, for this app only.

Linux: the AppImage

  1. Allow the file to run: in your file manager's Properties, under Permissions, or in a terminal: 
    chmod +x Gusset-*.AppImage
  2. Double-click it, or run it from the terminal.

If nothing happens on Ubuntu 22.04 or newer, a helper library is missing: run sudo apt install libfuse2 (libfuse2t64 on Ubuntu 24.04).

If it stops with a message about the "SUID sandbox", start it with this switch, which turns off the sandbox Gusset's browser engine runs in:

./Gusset-*.AppImage --no-sandbox

Check your download

The download page lists each file's SHA-256 checksum. Run the line for your system in the folder with the file, and compare the result with that list:

Windows (PowerShell)

Get-FileHash .\the-file-you-downloaded

Mac

shasum -a 256 the-file-you-downloaded

Linux

sha256sum the-file-you-downloaded
