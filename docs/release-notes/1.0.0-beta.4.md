# Gusset – Pattern Drafter 1.0.0 beta 4

Gusset is a free program for drafting sewing patterns in 2D, with a 3D window where you can sew the patterns together and try them on an avatar. Everything runs on your own computer, and your patterns stay there.

This beta brings a rebuilt Pleats tool, real grading tools, a sleeve you can actually pull into place, Seamless Blocking, Re-drape, and many smaller tools. It also makes saved files complete: a file opened on another computer now looks and behaves exactly as it did when you saved it. It is still a test version, so **please save your work often**.

**The easiest way to get it is the website:** [gussetdrafter.com](https://gussetdrafter.com/download) offers the right file for your computer, and you can also try Gusset in your browser with nothing to install.

## The first start

The builds are not signed yet, so Windows and macOS warn you the first time. [Install help](https://gussetdrafter.com/help) shows what to click:

- **Windows:** in "Windows protected your PC", click **More info**, then **Run anyway**.
- **Mac:** click **Done**, then System Settings ▸ Privacy & Security ▸ **Open Anyway**. If macOS says the app is damaged, run this in Terminal: `xattr -cr "/Applications/Gusset – Pattern Drafter.app"`
- **Linux:** allow the AppImage to run as a program. On Ubuntu 22.04 or newer you may need `libfuse2` (`libfuse2t64` on 24.04).

## If you tested a beta before

- **Your settings, library and unsaved work stay where they were.** Files from every earlier beta open as they were.
- **Files saved in beta 4 may not open in older betas.** The file format changed (it now holds more, see "Files" below). Keep a copy saved by your old beta if you need to go back to it.

## What's new since 1.0.0 beta 3

### Pleats

- **The Pleats tool works the way it does in practice.** Picking the tool opens nothing. Click two places on the outline (or one straight internal line) to make the pleat line, then click the side the pleats fold towards: an arrow shows it.
- The Pleats box then shows the pleats **live on the pattern** as you change them: Knife, Box or Accordion, the number of pleats (with ▲ ▼ buttons), depth, the spacing at each end, notches, and the fold directions. OK makes them in one step; Cancel leaves the pattern untouched.

### Grading

- **A new document starts with no sizes.** Click **+ Size Group** in the Grading tab when you want to grade. Older files keep their sizes.
- **Four grading tools**, in their own place on the 2D toolbar and under 2D ▸ Grading: Edit Grading and Edit Curve Grading, each also as "(Each)". Select points, then press the arrow keys: every size moves, each one step further than the one before it. The "(Each)" tools move only the size you picked. Alt moves a tenth of a step.
- **A grading table** in the Property Editor: type the distance or offset for each size, or for all of them at once.
- Curve points can be graded too, and a locked size never moves.
- **Each size can have its own colour**: click its swatch in the Grading tab. Smaller sizes stay dashed, so you can still tell them apart without colour.

### 3D

- **Pulling a sleeve moves the sleeve.** While simulating, a drag now takes a handful of cloth rather than one point, and the cloth around it slides over the body while you hold it. Pulling a T-shirt's cuff forward moves the whole sleeve more than twice as far as before, and more of the move stays when you let go.
- **Re-drape** (3D ▸ Arrangement): change the avatar's size or pose, then Re-drape. The garment is carried along with the body and simulated from there, instead of starting again from the arrangement.
- **Simulation Quality** (3D menu): Normal, or High Accuracy, which uses a finer cloth and more steps. It is slower and asks first.
- **Pins one at a time:** right-click a pin in the 3D window to delete it or attach it to the avatar.
- **Custom View** on the 3D window's right-click: look from any view you saved in the Render workspace, or add the current one.

### Seamless Blocking

- **Block lines** divide a pattern into sections without cutting it. Each section can have its own fabric, and its colour shows in 2D and on the cloth in 3D. For now this is the look only: the simulation uses the pattern's own fabric, and the Property Editor says so.
- **Offset as Seamless Block Line** on a line's right-click makes block lines at a set distance.

### Editing patterns

- **Dart Cap** (Seam Allowance tool): the seam allowance across a dart's opening takes the shape it has when the dart is sewn and pressed, toward either side.
- **Link to Pattern Outline** (right-click an internal line): the line keeps its distance from the edge. Move the edge and the line follows. **2D ▸ Edit ▸ Edit Link** lists every link in the document, each with Unlink.
- **Half Symmetric Pattern (with Sewing)** (a pattern's right-click ▸ Apply Linked Editing): two patterns that already mirror each other become a symmetric pair. Their seams are then sewn on both sides at once, as with Symmetric Pattern copies.
- **Trace as a Pattern (with Link)** (Trace, Shape mode): traced copies that follow their source.
- **Link Line** (Edit Sewing): the two sides of a seam change length together, keeping the ease between them.
- **Topstitch:** Assign to New Topstitch, and Add Internal Line on Topstitch, on Edit Topstitch's right-click.
- **Group, Ungroup and Distribute** (Edit ▸ Context Menu ▸ 2D Pattern): one click selects a whole group; Distribute spaces three or more patterns evenly.
- **Trace, Line mode:** right-click a line for Cut, Cut & Sew and Convert to Hole.
- **Base lines** can only be drawn inside a pattern now. Before, they could end up in a pattern you had selected but were not drawing in.

### The background image

- **Edit Background Image** (the empty 2D window's right-click): drag to move it, drag a corner to scale it (Shift keeps its proportions), turn it with the ring above it (Shift for 15° steps), and set its opacity in the Property Editor.

### Files

- **A saved file now holds everything.** Open it on another computer, or on a fresh install, and you get the same thing you saved: garment measurements, render settings, the avatar's collision detail and pose file, and the 3D origin in the history are all in the file now. Before, some of these came from the computer the file was opened on.
- **Unsaved work recovered after a crash keeps its history** of undo steps. Before, the timeline started empty.
- **Large files show a progress line** while they open.
- **The bug information** (Help ▸ Send Feedback) now names your graphics card, which helps us when something froze or a render failed. It holds nothing about you or your patterns.

### The window

- The Object Browser's **Scene** tab comes first (the Patterns tab still opens at the start).
- The bottom bar is taller, with bigger buttons with pictures. Fold Arrangement, Reset 2D Arrangement and Reset 3D Arrangement are separate buttons.

## Known issues

- **The simulation is a proof of concept.** It shows roughly how a garment hangs. It is not accurate enough to judge fit.
- **A pulled sleeve still stops about 10 cm forward**, because the arm is inside it. The avatar's arm itself does not move.
- **Seamless Blocking changes only the look.** Each section shows its fabric, but the whole pattern simulates with the pattern's own fabric.
- **Re-drape** does not carry cloth that hangs more than about 15 cm from the body. **Auto 3D Arrangement** is not built yet.
- **Simulation Quality is a setting of your computer**, not of the file. A file simulated in High Accuracy on one computer simulates in Normal on another unless it is switched on there too.
- **The undo history keeps the last 50 steps**, in the program and in the file. Undoing a step does not bring back how the cloth hung at that step, only before and after each simulation.
- **Unsaved work recovered after a crash** names your own avatar but does not hold it: load the avatar again to see the drape. Saved files hold it.
- **Once patterns are graded, the base size cannot be changed.**
- **Symmetric sewing** works only on a Symmetric Pattern copy (not an Instance copy), and only when the pattern has exactly one such copy. Zippers are not mirrored, and neither are seams on internal shapes of an unfolded pattern.
- **Convert to Handle Curve** still makes curve handles. It stays because Curve Grading works only on handle curves.
- **The path tracer gets ready again at every start of the program**, about 20 seconds on a mid-range graphics card. On cards that cannot do this in the background, it happens when you click Final Render.
- **Without a graphics card,** Final Render uses Quick. Path Traced can take many minutes for a large picture.
- **On some graphics cards the real size limit for a picture is only found by trying.** If a render fails with "the graphics card gave … pixels", the limit is lowered for the session: try again.
- **The Studio High Contrast light preset is much darker path traced** than in Quick. Burn Value brightens it. A path-traced picture can show a horizon line where the floor meets the background.
- **A saved turntable video needs the Render tab in front** while it is written.
- **A file saved in a browser** keeps a Particle Distance under 10 mm, but its saved drape is the browser's coarser one until it is simulated in the desktop app.
- **The fabric presets, the size run and parts of the skirt block are placeholder values,** to be replaced by real ones.
- **DXF output has not been tried on a cutter.**
- **Printing true to size depends on printing at 100 %.** Measure the 50 mm square on the first sheet.
- The project-file import is known for files written in 2026 only.
- On Apple-chip Macs, a fold line at 270° settles a little further from its target than elsewhere, and a fold's crease can look wavy on any computer.
