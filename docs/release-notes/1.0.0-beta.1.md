# Gusset – Pattern Drafter 1.0.0 beta 1

Gusset is a free program for drafting sewing patterns in 2D, with a 3D window where you can sew the patterns together and try them on an avatar. Everything runs on your own computer, and your patterns stay there.

This is the first public test version. Some things are missing and some will go wrong, so **please save your work often**.

**The easiest way to get it is the website:** [gussetdrafter.com](https://gussetdrafter.com/download) offers the right file for your computer, and you can also try Gusset in your browser with nothing to install.

## The first start

The builds are not signed yet, so Windows and macOS warn you the first time. [Install help](https://gussetdrafter.com/help) shows what to click:

- **Windows:** in "Windows protected your PC", click **More info**, then **Run anyway**.
- **Mac:** click **Done**, then System Settings ▸ Privacy & Security ▸ **Open Anyway**. If macOS says the app is damaged, run this in Terminal: `xattr -cr "/Applications/Gusset – Pattern Drafter.app"`
- **Linux:** allow the AppImage to run as a program. On Ubuntu 22.04 or newer you may need `libfuse2` (`libfuse2t64` on 24.04).

## If you imported project files before this version: re-read your grainlines

**Patterns imported from a project file by beta 4 or earlier may have their grainlines turned by 90°**, and the difference shows as soon as you lay them out in Print Layout. Your patterns themselves are fine. To put it right:

1. Open your pattern file.
2. Choose **File ▸ Import ▸ Re-read Grainlines from Original File…**
3. Pick the original `.zprj` or `.zpac`.

Each pattern's grainline is read again, even if you have moved or turned the pattern since. It is one step, so Undo takes it back. Opening an older file whose history shows such an import offers this once.

## What's new since 0.9.0 beta 4

### Installing and updating

- **A Windows installer** beside the portable `.exe`: for your user only, with no administrator password. Uninstalling leaves your settings and unsaved work alone.
- **Updates:** Gusset asks at the start whether a newer version is out (Settings ▸ User Settings ▸ Updates switches that off; Help ▸ Check for Updates… asks any time). If there is one, an **Update available** button appears at the top right. With the installer or the AppImage, a click downloads it and **Restart to Update** installs it, asking first if there is unsaved work. With the portable `.exe` or on a Mac, the button opens the download page. Nothing is downloaded or installed without your click. Test versions are offered test versions and final ones; final versions only final ones.
- **The name in full, Gusset – Pattern Drafter,** in the title bar, the installer, the shortcuts and Help ▸ About.
- A short start-up picture while Gusset loads; a click skips it. With reduced motion switched on in your system, it stands still.

### Print Layout

- **Every pattern lies with its grainline along the roll,** and turns only as its Grain Orientation allows (a new row in the Property Editor).
- **Manual Nesting:** a drag or a nudge keeps the spacing from the other patterns and stays inside the roll.
- **Patterns that overlap** are hatched, with a ⚠, and counted in the status bar.

### Drafting and seam allowances

- The seam allowance corners follow the corner's angle more closely, on slanted corners too: Perpendicular, Slant and Pocket.
- A notch at a corner can point along the corner's middle.
- Export ▸ OBJ asks for one object or one per pattern, and remembers your choice.

### Simulation

- **Solidify** has a Strength.
- **Simulation Shrinkage** runs from 1 to 1000 %, and a glue's Strength from 0.1 to 100.
- A glue can be switched off and kept.
- **Flip Normal** keeps a pattern's folds.

### Export and import

- **Holes in a DXF** are written the way pattern software expects. We have not yet proven that every program reads them as holes, so please tell us what you see.
- Grainlines from project files are read correctly (see above).

### Fixed

- **Trace as Pattern on an open internal line** could stop the 2D window drawing until you closed the program. The row is now greyed and says why.
- **Copy Grading** on a pattern with no grading no longer fails.
- **Settings ▸ Preferences ▸ 3D Grid Brightness…** now opens. It never could before.
- **Undo of Reset 2D Arrangement (All)** brings back the place where new patterns are laid out.
- **Buttons that open a list or panel** close it again with a second click.
- The program's text now uses one spelling, American.

The desktop app now runs on Electron 45, with the current security fixes.

## Known issues

- **The simulation is a proof of concept.** It shows roughly how a garment hangs. It is not accurate enough to judge fit.
- **The fabric presets, the size run and parts of the skirt block are placeholder values,** to be replaced by real ones.
- **DXF output has not been tried on a cutter.**
- **Printing true to size depends on printing at 100 %.** Measure the 50 mm line on the first sheet.
- The project-file import is known for files written in 2026 only.
- On Apple-chip Macs, a fold line at 270° settles a little further from its target than elsewhere.
