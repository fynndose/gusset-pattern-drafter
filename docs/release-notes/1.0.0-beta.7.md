# Gusset – Pattern Drafter 1.0.0 beta 7

Gusset is a free program for drafting sewing patterns in 2D, with a 3D window where you can sew the patterns together and try them on an avatar. Everything runs on your own computer, and your patterns stay there.

This beta brings **new seam allowance corners, a more lifelike pull on the cloth, and fabrics per section**, plus fixes to folds, the example skirt and undo while simulating. It is still a test version, so **please save your work often**.

**The easiest way to get it is the website:** [gussetdrafter.com](https://gussetdrafter.com/download) offers the right file for your computer, and you can also try Gusset in your browser with nothing to install.

## The first start

The builds are not signed yet, so Windows and macOS warn you the first time. [Install help](https://gussetdrafter.com/help) shows what to click:

- **Windows:** in "Windows protected your PC", click **More info**, then **Run anyway**.
- **Mac:** click **Done**, then System Settings ▸ Privacy & Security ▸ **Open Anyway**. If macOS says the app is damaged, run this in Terminal: `xattr -cr "/Applications/Gusset – Pattern Drafter.app"`
- **Linux:** allow the AppImage to run as a program. On Ubuntu 22.04 or newer you may need `libfuse2` (`libfuse2t64` on 24.04).

## What's new since 1.0.0 beta 6

### New seam allowance corners

You choose a corner's style where you did before; these styles now look as they should.

- **Round** is an arc that touches both cut lines one seam allowance back from the corner.
- **Envelope** stops each cut line a set distance back along its own seam line and bends in towards the corner's middle.
- **Pocket Style 2** is a zigzag, and the new **Pocket Style 3** is a step down to the seam line. Neither has distances to type in; Style 1 keeps its two.

### Sewing

- **A seam shows before you click.** Once one side is picked, the seam you are about to make is drawn with dotted connectors from start to start and end to end, in the 2D window and between the two cloths in 3D. The running lengths are shown at the pointer, as before.
- **Turned seams stay flat.** A seam whose Sewing Line Type is Turned no longer folds the two patterns back to back.
- **Superimpose** lays a pattern 3 mm off the one it is sewn to (it was 8 mm).

### The cloth

- **Pulling the cloth while it simulates feels real.** The place you hold stays exactly under the mouse, the cloth may stretch further while you hold it, and when you let go it springs back over about two seconds.
- **Each pull is its own undo step.** Ctrl+Z puts the cloth back as it hung before your last pull (the simulation stops first); press it again for the pull before that.
- **Seamless Blocking sections simulate with their own fabric.** Each section of a pattern now hangs with its fabric's weight, stretch, bending and friction, not only its look.
- **Folds and pleats settle straight.** A fold line's crease used to come to rest wavy, each part at a slightly different angle. It now lies straight at the angle you set.

### Small fixes

- **The example skirts' waistband sits properly.** In File ▸ Open Example, the skirt's waistband starts wrapped round the waist, so it no longer turns over into itself when you simulate.
- **The README lists every keyboard shortcut,** the same list as Help ▸ Keyboard Shortcuts…, made from the program itself so the two always agree.

## Known issues

- **Changing an early step does not yet update the later steps.** If you go back from the History panel, change something and keep the old steps as a branch, that branch stays exactly as it was: it is not redone on top of your change. That comes in a later version.
- **Fold Arrangement turns the cloth as it hangs and does not simulate.** Press Simulate afterwards if you want the folded part to settle.
- **The avatar's waist is found automatically** (the narrowest place between the hips and the chest). On your own avatar, if no waist can be found, the outline is placed by an estimate: use Edit Avatar Outline to move it.
- **Split Off copies do not follow the original.** Changing the original group later does not change the copies, and the other way round.
- **Going back in one group** takes along that group's patterns and the seams, topstitches and marks between them. Sewing from the group to a pattern outside it stays as it is.
- **How the cloth hung is kept only at Save States** and at a few other places. Going to any other step says "This step's cloth was not kept: Re-drape or Simulate", and nothing starts by itself.
- **The history keeps at most 500 steps.** Older steps are dropped, but never Save States or the points where a branch starts.
- **The simulation is a proof of concept.** It shows roughly how a garment hangs. It is not accurate enough to judge fit.
- **The avatar's arm does not move,** so a sleeve pulled forward on it cannot go further than the arm inside it allows.
- **A Seamless Blocking section's edge follows the cloth's triangles,** not the block line exactly, and a blocked pattern stays one piece in Print Layout.
- **Re-drape** does not carry cloth that hangs more than about 15 cm from the body. **Auto 3D Arrangement** is not built yet.
- **Simulation Quality is a setting of your computer**, not of the file. A file simulated in High Accuracy on one computer simulates in Normal on another unless it is switched on there too.
- **Once patterns are graded, the base size cannot be changed.**
- **Symmetric sewing** works only on a Symmetric Pattern copy (not an Instance copy), and only when the pattern has exactly one such copy. Zippers are not mirrored, and neither are seams on internal shapes of an unfolded pattern.
- **Convert to Handle Curve** still makes curve handles. It stays because Curve Grading works only on handle curves.
- **The path tracer gets ready again at every start of the program**, about 20 seconds on a mid-range graphics card. On cards that cannot do this in the background, it happens when you click Final Render.
- **Without a graphics card,** Final Render uses Quick. Path Traced can take many minutes for a large picture.
- **On some graphics cards the real size limit for a picture is only found by trying.** If a render fails with "the graphics card gave … pixels", the limit is lowered for the session: try again.
- **The Studio High Contrast light preset is much darker path traced** than in Quick. Burn Value brightens it. A path-traced picture can show a horizon line where the floor meets the background.
- **A saved turntable video needs the Render tab in front** while it is written.
- **A file saved in a browser** keeps a Particle Distance under 10 mm, but its saved drape is the browser's coarser one until it is simulated in the desktop app.
- **The fabric presets, the size run and parts of the skirt block are placeholder values,** to be replaced by real ones.
- **DXF output has not been tried on a cutter.**
- **Printing true to size depends on printing at 100 %.** Measure the 50 mm square on the first sheet.
- The project-file import is known for files written in 2026 only.
